# Bridging Global Infrastructure to Address Local Challenge with HPC - Asst. Prof. Dr. Worawan Diaz C.

Studi Kasus:
Sesuai dengan kasus fiktif PT Maju Bersama di video, perusahaan mengalami kenaikan pendapatan namun arus kas (cash flow) terganggu akibat banyaknya piutang yang macet (Late Payment). Sebagai analis, kita akan mengimplementasikan model Random Forest (sama seperti salah satu node yang dipakai pemateri di KNIME) untuk memprediksi pelanggan mana yang cenderung terlambat membayar agar manajer bisa mengambil tindakan preventif.
